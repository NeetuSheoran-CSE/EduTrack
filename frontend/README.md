# EduTrack
`npm install && npm run dev` · Demo login: pick Admin / Teacher / Student, any password (6+ chars).
Backend-ready: `src/services/api.js` (REST client, `VITE_API_URL`), `src/context/Auth.jsx` (swap `login` for JWT), route guards in `App.jsx`.
Planned tables (MySQL): users, students, classes, attendance, fees, payments, exams, marks.
